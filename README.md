# Desafio Técnico: Divisão de Execuções entre Fundos

Este projeto tem como objetivo desenvolver um algoritmo genético que divida execuções de uma ordem entre fundos de investimento, respeitando alocações inteiras e minimizando a diferença entre o PU médio dos fundos e o PU médio da ordem.

## Entradas
- `alocacao_ordem.csv`: alocação da ordem entre os fundos
- `massa_execucoes_500_cenarios.csv`: execuções simuladas para 500 cenários

## Saídas
- `resultado_divisao.xlsx`: divisão final das execuções por fundo
- `explicacao_projeto.md`: explicação técnica do projeto
